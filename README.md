## Installation

### Swift Package Manager

Add this repository URL in Xcode using **File > Add Package Dependencies**, then
select the `QRCodeSwift` product. The package uses Swift 5 and retains the existing
CocoaPods API.

- Repository: `https://github.com/Tuluobo/QRCodeSwift.git`
- Product: `QRCodeSwift`

### CocoaPods

QRCodeSwift is available through [CocoaPods](https://cocoapods.org). To install
it, simply add the following line to your Podfile:

```ruby
pod 'QRCodeSwift'
```
